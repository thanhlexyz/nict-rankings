Setting up the OpenAlex key

  1. Create a key at openalex.org (the free tier has its own daily budget, separate from the shared anonymous one that is used up on this network).
  2. Put it in the shell that runs the pipeline: export OPENALEX_API_KEY=…. The scripts read it from the environment and never print or store it.
  3. Run make snapshot. If the free budget is too small for a full run, the scripts stop with a message and keep what they have.
